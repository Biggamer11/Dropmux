# v0.1.0-alpha.2 — AppImage preview

This release captures the complete `slim-row-3` source and packaging changes, including the one-row pane taskbar, workspace selector, and global pane pins.

## Requirements

**x86-64-v3 CPU with AVX2, Linux kernel 6.1 or newer, and a graphical Linux desktop.** Built from a CachyOS runtime snapshot; cross-distribution compatibility remains unverified. Not for ARM or older x86 CPUs.

Includes Python 3.14.7, GTK3, VTE, PyGObject/Pycairo, SQLite, tmux 3.7c, terminfo and supporting UI libraries. Uses software rendering. Host shells, fonts, display services and external developer tools remain external. Distrobox/Podman and Codex are optional external tools and are not included.

The AppImage starts directly on the host. New panes inherit their tmux server's configured shell; existing server environments remain intact. The separate source `launch.sh` still enters the `codex-tools` Distrobox. No existing configuration is migrated.

## Run

```sh
chmod +x Dropmux-x86_64-v3.AppImage
./Dropmux-x86_64-v3.AppImage --show
```

Without FUSE mounting:

```sh
./Dropmux-x86_64-v3.AppImage --appimage-extract-and-run --show
```

All bottom controls stay on one horizontal row. Select a workspace, click a pane to focus it, and right-click a pane to pin/unpin it globally. At narrow widths, scroll the bottom strip horizontally. Workspaces are tmux sessions; switching or clicking a pin does not launch duplicate terminals.

The tmux runtime is cached under `$XDG_CACHE_HOME/dropmux` (default `~/.cache/dropmux`) so detached sessions survive unmounting the AppImage. Do not delete that cache while its tmux sessions are active.

## Validation

Five backend unit tests, real tmux integration and all 40 GUI checks passed. Layout checked at 760x480 and 1600x700, including readable button widths, one-row alignment, horizontal overflow and pin focus transitions. Both normal AppImage startup and extract-and-run were checked. The final X11 runtime self-test mapped no UI shared libraries from outside the bundle.

This is an unsigned prerelease for testing, not a universally portable Linux build.
